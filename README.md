# FlowGrove — Catalogue Quality Review (Fictional Demo)

**An interactive demonstration of a small, review-only Excel/CSV product-data quality audit.**

This repository contains **fictional product records only**. It does not represent previous client work or verified commercial outcomes.

## What you can explore
- Toggle between the original synthetic supplier sheet and a proposed review.
- See examples of duplicate SKU flags, missing categories and inconsistent names.
- Notice that the duplicate SKU is **not automatically merged or deleted**; a real merchant must confirm what counts as a duplicate.
- See how even minor title/category edits require buyer-approved conventions.
- Use the linked FlowGrove intake form to discuss an actual project.

## Scope of the FlowGrove pilot
- Introductory offer: **C$125** for **20 straightforward** supplied product rows.
- Deliverables, subject to a written agreement: review spreadsheet, issue log, change log and one same-scope revision.
- No live Shopify/WooCommerce changes, product image editing, complex variants, invented descriptions, guessed SKUs, or guaranteed sales outcomes.
- Agency partnership pricing is separate.
- Source files must be client-authorized and suitable for secure review. Do not submit passwords, customer records or confidential information through an unsolicited link.

## How to run
Open `index.html` in a modern browser. The demo is entirely static and makes no external requests until a visitor explicitly follows the FlowGrove website/intake links. No build process, npm packages, tracking scripts or AI API keys are required.

## Technical verification
The source was tested on Windows with Playwright Chromium (desktop/mobile), including all six fictional records, both tab states, persistence of duplicate warnings, and the two intake calls to action. Automated smoke tests and screenshots are maintained in the *local* FlowGrove project; no generated screenshot or browser profile is committed here.
